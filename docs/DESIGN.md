# 디자인 가이드 — 새싹이 애니 스타일

웹 대시보드와 iOS 앱이 함께 쓰는 셀 애니메이션풍 디자인 규칙입니다.
두 플랫폼은 **같은 토큰 값과 같은 마스코트 좌표**를 써야 하며, 값을 바꿀 때는 양쪽을 함께 바꿉니다.

| 플랫폼 | 토큰 | 마스코트 | 주요 컴포넌트 |
|---|---|---|---|
| 웹 | `web/src/theme.css` | `web/src/components/CharacterAvatar.tsx` | `CharacterCard.tsx`, `TodayActivities.tsx`, `Icons.tsx` |
| iOS | `ios/WellnessGame/Views/Theme.swift` | `ios/WellnessGame/Views/CharacterAvatarView.swift` | `Components.swift`, `ContentView.swift`, `LoginSheetView.swift` |

화면 시안 원본은 [`docs/design/`](design/)에 있습니다.

## 1. 원칙

- **만화 컷처럼**: 모든 카드·칩·버튼에 굵은 잉크 외곽선을 두르고, 흐림 없는 오프셋 그림자로 띄웁니다.
- **셀 셰이딩**: 그라데이션 대신 평평한 면 두 단계(본색 + 그림자색)와 작은 하이라이트로 입체감을 냅니다.
- **채색 면 위 글자는 항상 잉크색**: 노랑·분홍·민트 같은 채색 면 위의 글자와 아이콘은 라이트·다크 모두 `on-pop`(#1F2340)입니다.
- **이모지 금지**: 아이콘은 굵은 선 아이콘(웹 인라인 SVG, iOS SF Symbols)과 그려진 반짝이를 씁니다.
- **웹은 조회 전용**: 디자인을 바꿔도 웹에 기록을 만드는 UI는 넣지 않습니다.

## 3. 타이포그래피

| 역할 | 웹 | iOS |
|---|---|---|
| 제목·숫자 | Black Han Sans | 시스템 rounded, black 굵기 (`Font.display`) |
| 본문 | Jua | 시스템 rounded, semibold (`Font.rounded`) |

- 웹 폰트는 Google Fonts에서 `display=swap`으로 불러옵니다. iOS는 폰트 파일을 번들하지 않고 시스템 rounded로 대체합니다.
- iOS는 Dynamic Type을 따릅니다. 고정 높이 히어로 장면만 글자 크기 상한(`xxLarge`)을 둡니다.

## 4. 수치

| 항목 | 값 |
|---|---|
| 외곽선 두께 | 3 (칩·입력칸·작은 요소는 2.5) |
| 카드 모서리 | 22 (히어로 24, 칩 14, 버튼 16) |
| 오프셋 그림자 | 카드 4, 히어로 6, 버튼은 아래로 4~5 |
| 섹션 간격 | 18 |
| 최소 터치 영역 | 44 |

## 5. 컴포넌트

- **카드**: `card` 색 + 3 외곽선 + 오프셋 그림자. iOS `celCard()`, 웹 `.card`.
- **히어로**: 하늘색 패널 + 하프톤 점 + 두 겹 언덕, 말풍선(꼬리 포함), 반짝이 3개, 흔들리는 새싹이, 노란 기울어진 이름표 '새싹이', 레벨 칩. 데이터가 없으면 레벨 칩 대신 '아직 동기화 전'을 보여 줍니다.
- **EXP 바**: 높이 24, 사선 줄무늬가 흐르는 `xp` 채움, 채움 끝에 잉크 세로선. 최소 채움 10. 진행바 접근성 값은 0~100(%)이고 문구는 `aria-valuetext`/`accessibilityValue`로 전달합니다.
- **스탯 타일**: 위쪽 색 띠(스탯 색) + 잉크 아이콘, 큰 숫자, 'STR 근력' 라벨. 4열.
- **퀘스트 카드**: 46 크기 틴트 아이콘 상자, 제목·부제, 오른쪽 '+N XP' 노란 칩. 아이콘 상자 틴트는 항상 밝은 채색(다크 모드 카드색 금지 — 잉크 아이콘이 안 보임).
- **섹션 제목**: 기울어진 브랜드 그린 막대 + 굵은 제목.
- **버튼**: 3 외곽선 + 아래로 떨어지는 그림자, 누르면 그림자 쪽으로 내려앉습니다. 주요 버튼은 `yellow`. 카카오 `#FEE500`, 네이버 `#03C75A` 위 글자는 잉크/남색(흰 글자는 대비 부족).
- **경고 박스**: `danger-bg` + 외곽선, `danger-text` 문구. iOS `DangerNotice`.

## 6. 새싹이 — 성장 단계와 표정

화분에 사는 마스코트입니다. 120×120 좌표계를 쓰며 웹과 iOS의 경로 문자열은 **바이트 단위로 같아야** 합니다.
(iOS는 작은 SVG 경로 파서로 웹 문자열을 그대로 읽습니다.)

| 단계 | 레벨 | 모습 | 표정 |
|---|---|---|---|
| 씨앗 | 1–2 | 흙 위 씨앗 | 잠든 얼굴 |
| 새싹 | 3–5 | 잎 두 장 | 큰 눈 + 하이라이트 |
| 줄기 | 6–9 | 긴 줄기 + 잎 네 장 | 큰 눈 + 하이라이트 |
| 어린나무 | 10–14 | 작은 수관 | 웃는 얼굴 |
| 나무 | 15–19 | 큰 수관 | 큰 눈 + 하이라이트 |
| 개화 | 20+ | 큰 수관 + 분홍 꽃 6송이 | 웃는 얼굴 |

- 레벨 구간은 `web/src/lib/growthStage.ts`와 iOS `GrowthStage`가 같아야 합니다.
- 공통 요소: 셀 셰이딩 화분(본색 `#F4A06C`, 그림자 `#DC7A4C`, 테두리 `#F9BC8A`), 볼 터치 `#FF8FB1`, 바닥 그림자.
- 장식용으로 쓸 때(빈 상태 등)는 스크린 리더에서 숨깁니다 (`decorative`).

## 7. 모션

| 대상 | 움직임 |
|---|---|
| 새싹이 | 위아래로 둥실 + 살짝 기울기, 약 2.6초 |
| 반짝이 | 커졌다 작아지며 회전, 1.8~2.3초, 서로 엇갈림 |
| EXP 바 | 사선 줄무늬가 오른쪽으로 흐름, 1.2초 |
| EXP 채움 | 값이 바뀌면 0.8초 동안 늘어남 |

웹 `prefers-reduced-motion`, iOS '동작 줄이기' 설정이면 모든 반복 애니메이션을 멈춥니다.

## 8. 접근성 체크리스트

- 글자 대비 4.5:1 이상 (24pt 이상 큰 글자는 3:1). 입력칸 테두리와 포커스 링은 3:1 이상.
- 포커스 링은 `--text` 색 3px.
- 아이콘만 있는 버튼에는 접근성 라벨을 붙입니다.
- 같은 정보를 두 번 읽지 않게 합니다 (예: EXP 문구는 진행바 값으로만 읽힘).

[`docs/design/`](design/)에 디자인 캔버스에서 만든 화면 시안 원본이 있습니다.

| 파일 | 화면 |
|---|---|
| `Main.dc.html` | 홈 (라이트) |
| `MainDark.dc.html` | 홈 (다크 · 밤하늘) |

- 시안은 디자인 캔버스용 형식(`.dc.html`)이라 브라우저로 바로 열면 일부가 깨질 수 있습니다. 색·간격·구성을 참고하는 원본으로 씁니다.
- 실제 구현은 시안과 문구·데이터가 조금 다를 수 있습니다 (예: 걸음 목표 진행바는 앱에 걸음 목표가 없어 빼고 걸음 수만 표시).
- 원본 캔버스는 claude.ai의 비공개 아티팩트라 소유자만 열 수 있습니다.
