## 1. 수집 경로

```
iPhone(HealthKit) ──┐
Apple Watch ─(HealthKit에 운동 기록)─┘→ POST /api/health-activities/sync → 서버(검증·XP·스탯) → DB
Android(Health Connect) ─────────────→ POST /api/health-activities/sync
웹·Watch 화면 ← GET /api/characters/me, GET /api/health-activities (조회 전용)
```

| 출처 | 동기화 시점 | 걸음 | 운동 | 수면 |
|---|---|---|---|---|
| **iOS** (`AppleHealthKitProvider`) | 앱 실행·포그라운드 복귀(최소 5분 간격) | 오늘 0시~지금 `stepCount` 합(반올림) | 오늘 0시 이후 시작한 `HKWorkout`. 분 = 일시정지 제외 활동 시간 반올림(최소 1분), 칼로리 = activeEnergyBurned, 거리 = totalDistance | 전날 12:00~지금 asleep 샘플(Core/Deep/REM/Unspecified). 겹침 병합, 첫 구간 시작~마지막 구간 끝, 점수는 시간 기반 추정 |
| **Apple Watch** | — | — | `HKWorkoutSession`으로 HealthKit에 기록만 함. 서버 전송은 iPhone이 HealthKit에서 읽어 수행 | — |
| **Android** (`HealthConnectProvider`) | 앱 실행 + WorkManager 1시간 주기 | `StepsRecord` 합 | 오늘 0시 이후 `ExerciseSessionRecord`. PAUSE/REST 세그먼트 제외 | `SleepSessionRecord`의 SLEEPING/LIGHT/DEEP/REM 단계(없으면 세션 전체) |
| **웹** | — | 조회 전용, 기록 생성 없음 | | |

운동 종목 매핑: RUNNING(트레드밀 포함) · WALKING · CYCLING(실내 포함) · SWIMMING(풀·오픈워터) · STRENGTH_TRAINING(웨이트 포함) · 그 외 OTHER

## 2. 요청 검증 (`HealthActivitySyncValidator`)

**요청 전체 거부(400)**
- 활동 0개 또는 50개 초과
- `date`가 서버 기준 오늘 ±1일 밖
- 필수 값 누락(걸음 수, 운동 시작·종료, 수면 분·시작·종료), 종료 < 시작

**해당 항목만 건너뜀(0 XP, "기록을 반영하지 않았어요: 사유")**

| 구분 | 조건 |
|---|---|
| 공통 | 시각이 현재+5분보다 미래 / 시작이 `date` 전날 00:00 이전 / 종료가 `date` 다음날 24:00 이후 |
| 걸음 | 0~100,000 밖 / **`date`가 오늘보다 뒤 (#107)** |
| 운동 | 구간 0 이하 / 구간·분 720분(12시간) 초과 / 칼로리 0~10,000 밖 또는 분당 20kcal 초과 / 거리 0~500km 밖 / **분 > 실제 구간(30초 이상 올림), +1분 허용 제거 (#107)** |
| 수면 | 0~960분 밖 / 점수 0~100 밖 / **깬 시각의 서버(KST) 날짜가 요청 `date` ±1일 밖 (#107, 해외 시간대 고려)** |

## 3. 중복·겹침 처리

| 종류 | 단위 | 규칙 |
|---|---|---|
| 걸음 | 사용자·날짜당 1건 | 더 큰 값이 올 때만 갱신, 차액 XP만 지급 |
| 수면 | 사용자·날짜당 1건 | 더 긴 수면이 올 때만 갱신. 다른 날짜로 이미 반영된 수면과 시간이 겹치고 더 늦게 끝나지 않으면 "다른 날짜로 이미 반영됨"(0 XP) → 같은 수면을 날짜만 바꿔 다시 받을 수 없음 (#107) |
| 운동 | 시작·종료·종목 | 같은 기록 재전송은 중복. 다른 운동과 시간이 겹치면(경계 접촉 제외) 나중 것 건너뜀. 단 5분 미만 운동은 겹침 판정에서 제외 (#107) |

지급한 XP는 회수하지 않습니다. 같은 사용자의 동시 동기화는 캐릭터 행 잠금으로 순서대로 처리합니다.

## 4. XP 환산 (`ActivityXpCalculator`)

| 종류 | 공식 | 활동 상한 |
|---|---|---|
| **걸음** | `floor(걸음/1000) × 5` + 8,000보 달성 시 +30 | 100 |
| **운동** | **5분 미만이면 0 (#107)**. 그 외 `round(분×3 + floor(kcal/10) + 종목보너스)` | 운동 1건 200 |
| **수면** | 시간 정액 + 점수 80 이상이면 +20 | 80 |

- 운동 종목 보너스: 수영 20 · 달리기 15 · 자전거 15 · 근력 15 · 걷기 5 · 기타 0 (거리는 XP 미반영)
- 수면 정액: 7~9시간(420~540분) 60 · 9시간 초과 40 · 6~7시간 40 · 5~6시간 25 · 5시간 미만 10
- 수면 점수가 없으면 추정: 7~9시간 90 · 6시간 이상 70 · 5시간 이상 50 · 그 외 30

## 5. 하루 상한 (사용자·날짜)

- 전체 **600 XP**, 그중 운동 **400 XP**
- 지급액 = min(획득, 전체 남은 한도, 운동 남은 한도). 잘리면 "(일일 XP 상한 도달)" 표시
- 운동은 **시작 시각의 서버(KST) 날짜**, 걸음·수면은 요청 `date` 기준

## 6. 능력치(스탯) 환산 — **XP가 실제로 지급된 항목만 (#107)**

| 활동 | 스탯 |
|---|---|
| 근력 운동 | STR +2, VIT +1 |
| 수영·달리기·자전거·걷기 | VIT +2, STR +1 |
| 기타 운동 | STR +1, VIT +1 |
| 걸음 | 그날 처음 XP 지급 시 DISCIPLINE +1, 8,000보 달성 시 DISCIPLINE +1 |
| 수면 | 그날 처음 XP 지급 시 RECOVERY +1, INT +1 (점수 80 이상이면 INT +1 추가). 이후 점수가 80 이상으로 처음 오르면 INT +1 |

5분 미만 운동, 상한 소진으로 0 XP가 된 항목, 중복·겹침·거부 항목은 스탯이 없습니다. 기본 스탯은 그날 처음 XP가 지급될 때로 미뤄지지만, 상한 소진 상태에서 넘은 목표·수면 품질 보너스 스탯은 소멸합니다.

## 7. 레벨

- 다음 레벨까지 필요 XP = `100 + (레벨 − 1) × 50` (Lv1→2: 100, Lv2→3: 150 …)
- 초과분은 이월되고 한 번에 여러 레벨이 오를 수 있음
